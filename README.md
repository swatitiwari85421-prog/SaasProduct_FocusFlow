# 🚀 FocusFlow – SaaS Productivity Website

## 📌 About the Project

FocusFlow is a modern SaaS website designed with a clean, attractive, and user-friendly interface. It focuses on providing a smooth browsing experience with well-organized sections and responsive layouts.

## ✨ Features

- Modern and clean UI design
- Responsive website layout
- Features section
- Pricing section
- Easy navigation
- Mobile-friendly interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Vite

## 💻 Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/swatitiwari85421-prog/SaasProduct_FocusFlow.git
```

### 2. Navigate to the project folder

```bash
cd SaasProduct_FocusFlow
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🏗️ Build for Production

To create a production build, run:

```bash
npm run build
```
